# AirMate — 제품소개서

> AI 출국 메이트 · Product Brief v1.0 · 2026-04-03

---

## 한 줄 소개

> **항공권 스캔 한 번으로 출국 준비부터 귀국 차량 안내까지 — AI가 전부 연결해드립니다.**

---

## 문제 (Problem)

인천공항 연간 이용객 **3,000만 명**이 출국 당일 겪는 불편:

| 불편 | 빈도 |
|------|------|
| 수하물 마감 시간 놓침 | 5명 중 1명 |
| 게이트 변경 뒤늦게 인지 | 3명 중 1명 |
| 귀국 후 주차 위치 기억 못함 | 2명 중 1명 |
| 체크리스트를 직접 매번 작성 | 대부분 |

정보가 항공사 앱·공항 안내판·개인 메모로 **분산**되어 있어 통합 관리 불가.

---

## 솔루션 (Solution)

**항공권 OCR 스캔 → AI 자동 연결** 구조

```
📸 스캔 → ✅ 체크리스트 → ⏱ 출발 타이밍 → 🅿️ 주차 저장
                                    ↓
               ✈️ 실시간 알림 → 🧭 공항 내비 → 🏠 귀가 안내
```

- 스캔 즉시 항공편 정보 자동 등록
- AI가 목적지·기간 맞춤 체크리스트 자동 생성
- 게이트 변경·지연 실시간 푸시 알림
- 귀국 후 주차 위치 GPS 복귀 안내

---

## 핵심 기능 (Core Features)

### 🎯 MVP 기능 (1차)

| 기능 | 설명 |
|------|------|
| **항공권 OCR 스캔** | 사진·PDF·카카오톡 이미지에서 항공편 자동 추출 |
| **AI 체크리스트** | 여행지·기간 기반 맞춤 준비물 자동 생성 |
| **실시간 항공편** | 인천공항 공공데이터 기반 게이트·지연 정보 |
| **주차 GPS 저장** | 귀국 후 차량 복귀 원클릭 안내 |
| **푸시 알림** | 수하물 마감·게이트 변경 선제 알림 |

### 🎮 차별화 기능

| 기능 | 설명 |
|------|------|
| **캐릭터 시스템** | 여행 횟수·걸음수로 캐릭터 레벨업, 배지 수집 |
| **친구 초대** | 같이 여행하는 친구와 실시간 체크리스트 공유 |
| **공항 내 내비** | 면세점·라운지·식당 최적 동선 AI 추천 |

## 기술 스택

| 분류 | 기술 |
|------|------|
| Frontend | React 19 + TypeScript + Tailwind CSS |
| Backend | Supabase (PostgreSQL + Auth + Realtime) |
| OCR | 카카오 클로바 OCR / Google Vision |
| Push | Firebase Cloud Messaging (FCM) |
| 위치 | GPS + 인천공항 BLE Beacon |
| 항공 데이터 | 공공데이터포털 인천공항 API |
