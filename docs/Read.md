# ✈️ AirMate — AI 출국 메이트

> **항공권 스캔 한 번으로 여행이 시작됩니다.**
>
> 집에서 짐 싸기부터 귀국 후 내 차 찾기까지,
> 사용자의 '시간과 행동'을 설계하는 AI 여정 운영 플랫폼.

`✈️ 항공권 실시간 알림` `🅿️ GPS 주차 저장` `🤖 AI 동선 추천` `🎮 캐릭터 성장` `👫 친구 위치 공유`

## 01. 서비스 개요

기존 여행 앱이 정보를 **"보여주는"** 서비스라면,
AirMate는 사용자의 여정을 **"운영하는"** 서비스입니다.

항공권 스캔을 시작점으로, 출국 전 준비부터 귀국 후 귀가까지
전 과정의 행동을 AI가 설계하고 실시간으로 안내합니다.

- ✓ 항공권 스캔 = 여행 시작 버튼
- ✓ 출국 전 준비부터 귀국까지 All-in-One
- ✓ AI가 행동 시점 · 동선 실시간 추천
- ✓ 단순 정보 제공이 아닌 행동 운영

## 05. 사용자 여정

> 집에서 출발 → 공항 도착 → 탑승 → 귀국까지 7단계 완전 케어

### 🏠 STEP 0 · D-Day 전 — 출국 전 준비
- 📋 AI 맞춤 체크리스트
- 📄 여권 · 서류 관리
- 💱 환전 신청
- 🚗 자차 경로 · 통행료
- 🎮 준비 완료 경험치

> "오사카 3박 — 얇은 겉옷, 보조배터리(용량 확인!), 엔화 준비"

### 🅿️ STEP 1 — 공항 주차
- 🅿️ GPS 차 위치 저장
- 💰 주차 요금 안내
- 🧮 예상 요금 자동 계산
- 💡 할인 정보

> "3박 4일 기준 예상 요금: 약 36,000원"

### ✈️ STEP 2 · MAIN ⭐ — 항공권 실시간 확인
- 📸 항공권 사진 업로드 → OCR 자동 인식
- 🔔 지연 · 게이트 변경 즉시 푸시
- ❌ 결항 알림
- ⏰ 수하물 마감 타이머
- 🎫 온라인 / 현장 발권 안내

> "KE 723 · ICN → NRT · 출발 13:40 | 수하물 마감까지 ⏱ 2시간 20분"

### 🧭 STEP 3 — 체크인 & 보안검색
- ⏱ 보안검색 대기 시간 실시간
- 🪧 체크인 카운터 위치
- 🚪 출국심사 대기
- 📍 게이트까지 이동 시간

> "현재 3번 라인이 가장 빠릅니다 (대기 5분)"

### 🏢 STEP 4 — 공항 내부 탐색
- 🍽️ 식당 · 카페 · 🛍️ 면세점 · 💊 약국
- 🛋️ 라운지 · 🏧 ATM · 환전 · 📶 유심 수령
- 🎮 탐험 경험치

> "탑승까지 45분 남았어요. 3층 식당가 추천 (대기 10분)"

### 🛫 STEP 5 — 탑승 직전
- 🔔 탑승 D-15 · D-10 · D-5 단계 알림
- 🚪 게이트 변경 실시간 확인
- 🎮 비행 완료 보상

> "탑승 15분 전입니다. 게이트로 이동하세요 ✅"

### 🏠 STEP 6 — 귀국 & 집으로
- 📍 저장된 차 위치 안내
- 🛣️ 귀가 경로 추천
- 💰 실제 주차비 정산
- 🎮 여행 완료 배지

> "저장된 주차 위치: A구역 3층 → 지도 안내 시작 | 귀가 예상 1시간 15분"

## 06. 주요 기능

> 항공권 스캔 기반으로 연결되는 11개 핵심 기능

| 기능 | 설명 |
|------|------|
| 📸 항공권 스캔 (OCR) | 카카오 · 이메일 · 갤러리 · PDF에서 항공권 불러오기. OCR로 항공편 정보 자동 인식 및 여행 객체 생성 |
| 📋 AI 체크리스트 | 목적지 날씨 · 체류 기간 · 항공사 규정 · 사용자 프로필 기반 준비물 자동 생성 및 단계별 알림 |
| 📄 여권 & 서류 관리 | 여권 만료일 D-90/D-30/D-7 단계 알림. 비자 · 보험 · 예약 바우처 등 서류 통합 관리 |
| 🚗 출발 타이밍 추천 | 교통상황 · 통행료 · 공항 도착 권장 시간 종합 분석. "20분 내 출발 권장" 형태로 제공 |
| 🅿️ 주차 위치 저장 | GPS · 층 · 구역 · 사진 저장. 귀국 후 저장 위치로 경로 복원. 예상 주차비 자동 계산 |
| ✈️ 실시간 항공편 운영 | 지연 · 결항 · 게이트 변경 · 수하물 마감 · 탑승 시간을 푸시 알림과 행동 유도 문구로 연결 |
| 🧭 공항 AI 내비게이션 | 위치 · 대기시간 · 탑승 시각 종합 분석으로 최적 경로와 행동 시점 추천. 단순 길찾기 이상 |
| 🏢 공항 시설 탐색 | 식당 · 라운지 · 면세점 · ATM · 유심 등 위치 · 혼잡도 · 대기시간 제공. 시간별 맞춤 추천 |
| 🎮 캐릭터 게임화 | 식사 → 캐릭터 살 오르고, 걷기 → 건강, 늦은 이동 → 지침. 행동과 캐릭터 상태 연동 |
| 🚶 만보기 | 공항 내 걸음 수 · 이동 거리 · 칼로리 기록. 여행 단위 리포트 제공 및 캐릭터 성장 연동 |
| 👫 소셜 위치 공유 | 초대 링크 / 코드로 동반자 연결. 실시간 위치 공유 · 그룹 이동 보너스 경험치 제공 |

## 07. AI & 데이터 전략

> 5개 데이터 축으로 운영하는 행동 추천 AI 플랫폼

### ✈️ 항공편 데이터
- 항공편 번호 · 항공사 · 출도착 공항 · 터미널
- 게이트 · 체크인 카운터 · 탑승 시작 시각
- 지연 · 결항 · 수하물 마감 · 온라인 체크인 여부
- 수하물 규정 · 현장 발권 가능 여부

### 🏢 공항 안내 데이터
- 식당 · 카페 · 약국 · 환전소 · ATM 위치 · 운영시간
- 라운지 · 유심 · 수하물 보관소
- 롯데 / 신라 / 현대 면세점 층별 위치 · 혼잡도
- 보안검색 · 출국심사 대기시간

### 📍 위치 데이터
- GPS 좌표 · 터미널 · 층 · 구역
- 실내 위치 (비콘 / BLE / Wi-Fi RTT 하이브리드)
- 주차 위치 · 구역 · 요금 정보

### 🤖 AI 행동 추천 로직
- 현재 위치 + 탑승 남은 시간 + 게이트 이동시간
- 보안검색 대기 + 사용자 평균 이동 속도
- 동행 여부 · 선호 시설 · 혼잡도 종합 분석
- **추천 결과 = "다음 행동"** (콘텐츠 X)

## 08. 필요 API & 외부 연동

> 서비스 구현에 필요한 핵심 API 및 외부 연동 목록

| 분류 | 후보 | 설명 |
|------|------|------|
| 📝 OCR | CLOVA OCR · AWS Textract · Google Vision | 항공권 이미지 텍스트 추출. 한글/영문 혼합 인식 정확도 중요 |
| ✈️ 항공 데이터 | Amadeus · FlightAware · Aviationstack | 실시간 운항 정보 · 지연 · 게이트 변경. 장기적으로 공항공사 직접 연동 |
| 🗺️ 지도 & 경로 | 네이버 지도 · 카카오맵 · Google Maps | 차량 이동 경로 · 통행료 · 소요시간. 국내 MVP는 네이버/카카오 우선 |
| 📡 실내 위치 | 공항공사 데이터 · BLE Beacon | 터미널 내부 동선 안내. 비콘/BLE/Wi-Fi RTT 하이브리드 방식 |
| 🔔 푸시 & 메시징 | FCM · APNs · 카카오 알림톡 | 실시간 알림 전달. 중요 알림은 카카오 알림톡 · 문자 대체 채널 병행 |
| 🌤️ 날씨 & 기타 | 날씨 API · 금융 제휴 · 소셜 로그인 | 여행지 날씨 기반 준비물 추천. 환전 · 보험 · 유심 제휴 API 연동 |

## 09. 시스템 구성

> 입력 → 데이터 → AI → 서비스 → 비즈니스 5개 레이어

```
Input Layer     │ 항공권 이미지 · 사용자 프로필 · 위치 정보
Data Layer      │ 항공편 DB · 공항 시설 DB · 행동 로그 · 위치 데이터
AI Layer        │ OCR 파싱 · 일정 자동 생성 · 타이밍 추천 · 동선 최적화 · 개인화 추천
Service Layer   │ 알림 시스템 · 홈 화면 UI · 캐릭터 · 소셜 · 시설 탐색 UI
Business Layer  │ 광고 · 제휴 · 구독 관리 · B2B SaaS · 데이터 판매
```

## 10. 차별화 포인트

| # | 포인트 | 설명 |
|---|--------|------|
| 01 | 항공권 스캔 한 번 = 여행 자동 생성 | 사용자의 수동 입력을 최소화하는 "항공권 스캔 = 여행 시작 버튼" UX. OCR 인식 후 모든 기능이 자동 연결 |

| 04 | 캐릭터 · 만보기 · 소셜 결합으로 생활형 서비스 확장 | 리텐션 · 바이럴 강화를 위해 기능성 앱에 게임화 · 소셜 레이어를 결합한 구조 |
| 05 | 광고 · 제휴 · 데이터 · B2B 복합 확장성 | 공항 · 항공사 · 면세점 · 금융 · 리테일 제휴를 연결하는 플랫폼 사업 기반 동시 확보 |
