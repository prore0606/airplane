# AirMate — API 명세서

**PostgreSQL + Supabase 기준 | 총 42개 API | 인증: Supabase Auth JWT**

---

## 전체 API 요약

| 도메인 | API 수 | 비고 |
|--------|--------|------|
| 사용자 | 3개 | 회원 조회/수정/탈퇴. 회원가입은 Supabase Auth 처리 |
| 항공편 | 7개 | OCR 등록, 수동 등록, 조회/수정/삭제, 알림설정 |
| 주차 | 5개 | 위치 저장/조회/수정/출차처리/삭제 |
| 공항 시설 | 7개 | 시설/면세점/혼잡도 조회, 관리자 등록/수정/삭제 |
| 체크리스트 | 5개 | AI 생성, 조회, 항목완료, 삭제 |
| 알림 | 4개 | 목록조회, 읽음처리, 전체읽음, 삭제 |
| 게임화 | 4개 | 캐릭터조회, 경험치적립, 배지조회, 만보기저장 |
| 소셜 | 5개 | 친구 초대/수락/목록/위치공유/삭제 |
| AI 추천 | 2개 | 동선 추천, 출발 타이밍 추천 |
| **합계** | **42개** | |

---

## 1. 사용자

> 회원가입은 Supabase Auth가 처리. 우리가 만드는 API는 조회/수정/탈퇴 3개.

### `GET` /api/v1/users/me — 회원 조회

| 항목 | 내용 |
|------|------|
| 인증 | 필요 (로그인한 본인만) |
| 요청 바디 | 없음 |
| 응답 200 | `id`, `name`, `email`, `walking_speed`, `is_active`, `created_at` |
| 응답 401 | 로그인되지 않은 경우 |

### `PATCH` /api/v1/users/me — 회원 수정

| 항목 | 내용 |
|------|------|
| 인증 | 필요 (로그인한 본인만) |
| 요청 바디 | `name`, `walking_speed`, `fcm_token` (수정할 항목만) |
| 응답 200 | 수정된 회원 정보 전체 |
| 응답 401 | 로그인되지 않은 경우 |

### `DELETE` /api/v1/users/me — 회원 탈퇴

| 항목 | 내용 |
|------|------|
| 인증 | 필요 (로그인한 본인만) |
| 요청 바디 | 없음 |
| 응답 200 | 탈퇴 완료 메시지 (완전 삭제 아닌 `is_active = false` 처리) |
| 응답 401 | 로그인되지 않은 경우 |

## 2. 항공편

> OCR 등록과 수동 등록 두 가지 방식 지원. 실시간 운항 상태는 상세 조회 시 포함.

### `POST` /api/v1/flights — 항공권 등록 (OCR)

| 항목 | 내용 |
|------|------|
| 인증 | 필요 (로그인한 본인만) |
| 요청 바디 | 항공권 사진 이미지 파일 |
| 응답 200 | OCR 파싱 결과: `flight_number`, `airline_code`, `origin_iata`, `dest_iata`, `scheduled_dep`, `scheduled_arr`, `terminal`, `gate` |
| 응답 400 | 이미지 인식 실패 |

### `POST` /api/v1/flights/manual — 항공편 수동 등록

| 항목 | 내용 |

| 인증 | 필요 (로그인한 본인만) |
| 요청 바디 | `flight_number`, `airline_code`, `origin_iata`, `dest_iata`, `scheduled_dep`, `scheduled_arr`, `terminal` |
| 응답 200 | 등록된 항공편 정보 전체 |
| 응답 400 | 필수값 누락 |

### `GET` /api/v1/flights — 내 항공편 목록 조회

| 항목 | 내용 |
|------|------|
| 인증 | 필요 (로그인한 본인만) |
| 쿼리 파라미터 | `status` (선택), `page` (선택) |
| 응답 200 | 내 항공편 목록 전체 |
| 응답 401 | 로그인되지 않은 경우 |

### `GET` /api/v1/flights/{flightId} — 항공편 상세 조회

| 항목 | 내용 |
|------|------|
| 인증 | 필요 (로그인한 본인만) |

| 응답 200 | 항공편 상세 정보 + 실시간 운항 상태 |
| 응답 403 | 본인 항공편이 아닌 경우 |
| 응답 404 | 존재하지 않는 항공편 |

### `PATCH` /api/v1/flights/{flightId} — 항공편 수정

|------|------|
| 인증 | 필요 (로그인한 본인만) |
